# CDocPatientAndroid

# Set Up
Download Android Studio with the corresponding OS <br />
https://developer.android.com/studio
<br />
<br />

Follow the instructions to set up the Android Studio

# Run CDocPatientAndroid

1) Check out project from Version Control: Select Git <br />
https://github.com/JINPINYING/CDocPatientAndroid.git <br />
Then click clone
<br />
2) When the configuration is done, plug the device then click run at the top right to deployee the app. <br />
(Make sure your device is in developer mode. If not, go to setting -> about tablet -> find build number and click multiple times)

# Switch between General Mode and Tablet Mode
<br />
1) Go to CDoctor2 and find the manifest file under manifests folder <br />
For general mode: make enabled under .login.WelcomeActivity to true and enabled under .login.WelcomeActivityTablet to false.
For tablet mode: vice versa
